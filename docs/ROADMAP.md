# Roadmap

TriageKit is free and open source (GPL-3.0-only). Released versions are listed in the [changelog](../CHANGELOG.md).

## Now
- [ ] Signed releases through SignPath Foundation, built by GitHub Actions
- [ ] Testing on clean Windows 10 22H2 and 11 24H2/25H2 virtual machines, non-English Windows, standard users
- [ ] Throttling detection for AMD and Intel graphics through HWiNFO

## Next
- [ ] "Was I robbed?" timeline: when a session could have been stolen, from the evidence already collected
- [ ] Clipboard self-test: does anything swap a copied crypto address?
- [ ] Browser extension permission drift: warn when an update quietly adds powerful permissions
- [ ] Guided fixes for safe settings (turn on firewall, PUA blocking, tamper protection): opt-in, logged, reversible
- [ ] Submit releases to Microsoft and antivirus vendors as known-good

## Later
- [ ] Microsoft Store listing (as a signed EXE)
- [ ] Translations
